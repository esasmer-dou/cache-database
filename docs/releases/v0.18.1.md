# CacheDB 0.18.1

[Türkçe](../../tr/docs/releases/v0.18.1.md)

This patch hardens the 0.18.0 contracts. Source preparation is not publication:
the existing 0.18.0 tag and packages are not replaced. Do not select 0.18.1 from
the public Maven repository until it has actually been published.

## Changes and Rollout

| Risk | Change | Application action |
| --- | --- | --- |
| R-1 | Composite schema signatures; VERIFIED/PENDING_REBUILD/NONE diagnostics; bounded cleanup and correct single-column fallback | Regenerate bindings, deploy every writer, then run rebuildIndexes. A mixed-binding writer fleet is not safe to rebuild. |
| R-2 | JDBC regrouping planning counters and at most 1024 first-use entity log identities per flusher | Opt in only for order-independent schemas; monitor reorderedBatches, reorderedOperations and reorderSkippedMixedOptIn. |
| R-3 | Bounded per-slot causal reads and explicit task context capture | Propagate authenticated tenant and causal scope separately; atomic mutations still require shared hash tags. |
| R-4 | Lazy per-runtime refresh pool; at most 2 threads, 256 queued tasks, 258 reservations | Close the runtime; keep finite I/O timeouts. Java cannot forcibly terminate interrupt-ignoring tasks. |
| R-6 | Source/test directory alignment | Java package names and generated binary names are unchanged. |
| R-7 | Full reactor with live providers and anti-skip assertions in the existing provider workflow | Missing evidence fails the gate; a green unit-only run is insufficient. |

**R-5: Deferred to 0.19.0.** Tenant aggregates and facets retain their bounded,
correct pipeline path. No tenant/facet Lua speedup is claimed in this patch.

## Enable Independent Write Regrouping

```java
@CacheEntity(table = "supplier_offers", redisNamespace = "supplier-offers",
        independentWriteReordering = true)
public class SupplierOffer { /* persisted fields */ }
```

Every entity in the flush batch must opt in. Same `(table,id)` operations retain
their causal order. Leave this off for parent/child inserts, triggers reading
sibling rows, unique values swapped between rows, and other cross-row ordering
constraints. Counters report planning, not SQL commit.

See [causal wrappers, Cluster behavior and index lifecycle](../near-cache-facets-indexes.md)
and [write controls](../hot-path-controls.md).

The updated workflow and anti-skip guard are prepared locally; no new remote CI
run or publication is implied before push. The 50 ms gate is not an HTTP/WAN SLA.

The acceptance run must execute in the isolated EmaTech Kubernetes namespace,
using standalone Redis, a six-node Redis Cluster and disposable PostgreSQL,
SQL Server and Oracle fixtures. Retained Maven XML reports provide module totals;
`tools/ci/check-full-environment-tests.ps1` rejects absent/all-skipped mandatory
suites and skipped live refresh methods. Package/API checks apply to the same source.
This is not customer HA, WAN latency or application cutover certification.

The Redis Function library remains at ABI version 0.18.0 because this patch does
not change its Lua source. The Maven artifact version is 0.18.1; do not force a
different function-library version or reset existing Redis version counters.
