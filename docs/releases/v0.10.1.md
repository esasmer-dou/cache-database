# v0.10.1

Turkish version: [../../tr/docs/releases/v0.10.1.md](../../tr/docs/releases/v0.10.1.md)

Release tag: `v0.10.1`

CacheDB `0.10.1` is a stable distribution-consistency patch over `0.10.0`.
It does not change the runtime or generated public API.

## Fixed

- The PostgreSQL and SQL Server samples embedded in the framework repository
  now use the same anonymous Maven repository contract as the standalone
  sample repositories.
- Sample workflows no longer request redundant GitHub Packages permissions or
  credentials for the default build path.
- Every sample CI flow proves that `cachedb:certify` fails closed when the
  application evidence manifest or route coverage report is missing.
- Public Maven deployment uses the current Node 24 generation of the official
  GitHub Pages actions without the previous runtime deprecation warning.
- Current README, getting-started, provider, release, OpenRewrite, and package
  references consistently target the immutable `0.10.1` artifacts.

## Distribution

No token is required for the official Maven repository:

```xml
<repository>
    <id>cachedb-public</id>
    <url>https://esasmer-dou.github.io/cache-database/maven2</url>
</repository>
```

Use `0.10.1` for the BOM, provider starter, and Maven plugin. GitHub Packages
remains an optional authenticated mirror.

## Compatibility

- The `0.10.0` tag and artifacts remain immutable.
- No runtime or generated public API signature was removed or changed.
- PostgreSQL and SQL Server keep the same provider contract and evidence lanes.
- Application-specific production certification remains mandatory for each
  consuming application's own routes and staging topology.

## Verification

- Full reactor, public API, documentation, sample parity, and release artifact
  checks pass.
- Framework Readiness and Production Evidence must pass for the exact release
  commit before the tag is published.
- Both standalone samples must build from a fresh local Maven repository using
  the anonymous CacheDB repository.
- The GitHub Release contains the release ZIP, SHA-256 sidecar, and public
  binary JARs.
