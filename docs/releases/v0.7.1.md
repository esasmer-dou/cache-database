# v0.7.1

Release tag: `v0.7.1`

CacheDB `0.7.1` is the production patch for the `0.7` declarative repository
release. Framework runtime behavior is unchanged from `0.7.0`; the distribution
and consumer build contract is corrected.

## Fixed

- Sample POMs declare GitHub Packages under both `repositories` and
  `pluginRepositories`.
- `cachedb-maven-plugin:doctor` now resolves from GitHub Packages on a clean
  Maven runner instead of being searched only in Maven Central.
- Sample quick starts consume immutable published artifacts and no longer ask
  release users to install CacheDB framework sources locally.
- English and Turkish setup guidance explains why dependency and plugin
  repositories need the same Maven server ID and `read:packages` credentials.
- The release ZIP includes the corrected PostgreSQL and MSSQL samples alongside
  all 16 public binary/source/javadoc artifacts, module POMs, and the BOM.

## Consumer Version

```xml
<properties>
    <cachedb.version>0.7.1</cachedb.version>
</properties>
```

Use `0.7.1` rather than `0.7.0` for new consumers and sample-based onboarding.

## Validation Requirement

The PostgreSQL and MSSQL standalone consumer workflows must resolve the Maven
doctor plugin, BOM, annotation processor, starters, and test kit from the
published `0.7.1` package on clean GitHub-hosted runners. Each workflow then
runs its live Redis/provider integration test before the sample tag is created.

## Production Boundary

This patch corrects package consumption. It does not change the route coverage,
hot-set, write-behind, reconciliation, topology, or cutover responsibilities
documented in the `0.7.0` release notes.
