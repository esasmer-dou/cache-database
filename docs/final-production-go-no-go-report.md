# Production Go/No-Go

This page no longer maintains an independent readiness verdict.

Use the [Production Readiness Contract](../PRODUCTION_GA_CRITERIA.md) for the
current framework decision and [Production Certification](production-certification.md)
for a consuming application's cutover decision.

Historical benchmark output is evidence for the commit, workload, and topology
that produced it. It must not be reused as a general `GO` for another release
or application.
