# Sürüm Geçmişi

[English](../../docs/release-history.md)

| Sürüm | Kapsam |
| --- | --- |
| [0.19.0 - UNRELEASED](releases/v0.19.0.md) | Java 21'e geçiş ve on bir taslak özellik alanı. Sınırlı F3 kabulü yalnız taslak notlarda kimliği belirtilen aday içindir; genel sürüm kapıları ve uygulamaya özel koruma geçişi açıktır. Zorunlu 2x `rawT4target`, açık kabul istisnasıyla kaldırılmıştır; ölçülmüş PASS değildir. Yayım iddiası yoktur. [Geçiş taslağını](upgrading-to-0.19.md) okuyun. |
| [0.18.1](releases/v0.18.1.md) | Bileşik indeks koruması, causal Cluster/kapsam aktarımı, yenileme yaşam döngüsü ve tam ortam kontrolü. R-5 Lua optimizasyonu 0.19.0'a ertelendi. Yayın durumunu GitHub sürüm listesinden doğrulayın. |
| [0.18.0](releases/v0.18.0.md) | Toplu/SWR/causal L1 kontrolleri, gruplama, bileşik indeksler ve tenant kapsamlı işlemler. Dağıtımdan önce doğrulama sonuçlarını ve geçiş sınırlarını inceleyin. |
| [0.17.0](releases/v0.17.0.md) | Okuma/yazma iyileştirmeleri, sayısal değişimler, toplamlar, tenant kapsamı, yerel bildirimler ve veri biçimi geçişi. |
| [0.16.0](releases/v0.16.0.md) | Sınırlı okuma/yazma kontrolleri, kısmi güncelleme, snapshot değişiklik bildirimi, işlem birimi ve isteğe bağlı L1. |
| [0.15.1](releases/v0.15.1.md) | Veritabanına göre kolon bütçeleri ve geniş generated entity desteği. |

Yayımlanmış sürümler için [GitHub sürüm listesi](https://github.com/esasmer-dou/cache-database/releases)
esas alınır. Kaynak kodun sürüm numarası tek başına yayın kanıtı değildir.
