# v0.7.1

Sürüm etiketi: `v0.7.1`

CacheDB `0.7.1`, deklaratif repository özelliklerini içeren `0.7` hattının
production düzeltme sürümüdür. Framework'ün çalışma zamanı davranışı `0.7.0`
sürümüyle aynıdır; dağıtım ve consumer build sözleşmesi düzeltilmiştir.

## Düzeltilenler

- Sample POM'ları GitHub Packages adresini hem `repositories` hem de
  `pluginRepositories` altında tanımlar.
- `cachedb-maven-plugin:doctor`, temiz Maven runner'ında yalnızca Maven
  Central'da aranmak yerine GitHub Packages üzerinden çözümlenir.
- Sample hızlı başlangıç adımları değişmez yayın paketlerini kullanır; release
  kullanıcılarından CacheDB framework kaynaklarını yerel olarak kurmaları
  istenmez.
- İngilizce ve Türkçe kurulum rehberleri, dependency ve plugin repository
  tanımlarında neden aynı Maven server kimliği ile `read:packages` yetkisinin
  gerektiğini açıklar.
- Release ZIP'i düzeltilmiş PostgreSQL ve MSSQL örneklerinin yanında 16 public
  modülün binary/source/javadoc artefact'larını, modül POM'larını ve BOM'u
  içerir.

## Kullanılacak Sürüm

```xml
<properties>
    <cachedb.version>0.7.1</cachedb.version>
</properties>
```

Yeni consumer ve sample başlangıçları için `0.7.0` yerine `0.7.1` kullan.

## Doğrulama Koşulu

PostgreSQL ve MSSQL bağımsız consumer workflow'ları Maven doctor eklentisini,
BOM'u, annotation processor'ı, starter'ları ve test kitini yayımlanmış `0.7.1`
paketinden temiz GitHub runner'larında çözümlemelidir. Her workflow, sample tag'i
oluşturulmadan önce canlı Redis/provider entegrasyon testini de çalıştırır.

## Production Sınırı

Bu patch, paket tüketimini düzeltir. `0.7.0` sürüm notlarında açıklanan route
kapsamı, aktif veri seti, write-behind, uzlaştırma, topoloji ve cutover
sorumluluklarını değiştirmez.
