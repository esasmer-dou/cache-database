# v0.8.0

İngilizce sürüm: [../../../docs/releases/v0.8.0.md](../../../docs/releases/v0.8.0.md)

Sürüm etiketi: `v0.8.0`

CacheDB `0.8.0`; route sözleşmelerini daha açık hale getiren, sayfalama
devamlılığını güvenli biçimde taşıyan, arka plan işlerini sınırlayan ve uygulama
kodunu sadeleştiren kararlı bir framework sürümüdür. `0.7.1` sonrasında
tamamlanan kapsamlı framework kullanım deneyimi çalışmalarını içerir.

## Temel Değişiklikler

- Cursor artık üretildiği route'a, filtre veya parent kapsamına ve sıralama
  sözleşmesine bağlıdır. Başka bir route üzerinde kullanılırsa işlem açıkça
  reddedilir.
- `CursorPage<T>`, kayıtları ve `nextCursor` değerini service ile HTTP katmanları
  arasında taşır; controller'ın keyset ayrıntılarını bilmesi gerekmez.
- `@CacheRepositoryDefaults`; aktif veri kapsamını, sayfa/pencere sınırını,
  bellek bütçesini, kaynak okuma sınırını, zaman aşımını ve warm limitini
  repository seviyesinde toplar.
- `CacheMemoryBudget`, annotation içindeki anlaşılması güç ham byte değerlerinin
  yerine okunabilir sabitler sağlar.
- Repository yetenekleri, route population bilgisi, generated route catalog ve
  Spring Boot route envanteri reflection kullanmadan incelenebilir.
- Warm işlemlerinde tipli hedef, açık dry-run/apply modu, tutarlılığı doğrulanan
  özet ve tek dry-run/apply/coverage test akışı vardır.
- Dağıtık işler tek tipli tanımı ve boyutu sınırlı yapısal ilerleme bilgisini
  paylaşır.
- `CacheDurableBatchWriter`; import ve seed işlemlerinde batch gönderimini,
  receipt takibini ve sınırlı kalıcılık beklemesini framework içine taşır.
- PostgreSQL ile SQL Server örnekleri aynı deklaratif uygulama modelini, Bean
  Validation kurallarını, cursor cevabını, warm komutlarını ve testleri kullanır.

## Korunan Sınırlar

- HOT route yalnızca Redis'ten okur. Kayıt bulunamadığında görünmeyen bir SQL
  sorgusu çalıştırılmaz.
- SOURCE route, açıkça tanımlanan, sınırlı, indeksli ve zaman aşımı olan SQL
  okumasıdır.
- Yazı önce Redis tarafından kabul edilir; SQL kalıcılığı asenkron ilerler ve
  receipt üzerinden izlenir.
- Repository implementasyonları, route metadata'sı ve Spring adapter'ları
  runtime reflection kullanılmadan derleme zamanında üretilir.
- Büyüyen listelerde offset taraması veya tüm aggregate yerine projection ve
  keyset penceresi kullanılır.

## Kullanılacak Sürüm

```xml
<properties>
    <cachedb.version>0.8.0</cachedb.version>
</properties>
```

Yalnızca bir provider starter seç:

```xml
<dependency>
    <groupId>com.reactor.cachedb</groupId>
    <artifactId>cachedb-spring-boot-starter-postgres</artifactId>
</dependency>
```

veya:

```xml
<dependency>
    <groupId>com.reactor.cachedb</groupId>
    <artifactId>cachedb-spring-boot-starter-mssql</artifactId>
</dependency>
```

## Uyumluluk

`0.7.1` sonrasındaki public API değişiklikleri ekleme yönündedir. Önceki
sözleşmeler için uyumluluk overload'ları korunur. Yine de route varsayılanları
ve cursor sözleşmeleri daha açık hale geldiği için uygulamanı derleyip provider
entegrasyon testlerini çalıştırmadan production'a alma.

- PostgreSQL ve SQL Server provider entegrasyon örnekleri: hata ve başarısızlık
  yok.
