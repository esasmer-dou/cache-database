# CacheDB 0.12.0

Bu sürüm kaynak ve ilişki tanımlarını kısaltır.
Tutarlı okuma ve güvenli yayın sözleşmesi değişmez.

## Yenilikler

- Metadata ve codec tekrarları yerine üretilmiş SOURCE alanını kullanın.
- Eşitlik ve alt sorgulu IN koşullarında SQL birleştirmek yerine değer bağlayın.
- Scalar record'lar için @CacheSourceRecord ile dönüşüm kodu üretin.
- İlişki yönünü SnapshotRelation ile bir kez tanımlayın.
- Sıralı liste, üyelik ve köke göre DTO dağıtımını yenileme başında hazırlayın.

Kod örnekleri [kaynak başvurusunda](../snapshot-kaynak-basvurusu.md),
çalışma sözleşmesi [katalog rehberindedir](../snapshot-projectionlar.md).
Yeni kaynak yolu PostgreSQL, SQL Server ve Oracle için geçerlidir.
Sağlayıcının transaction koşulları değişmez.

## Yükseltme

BOM ve annotation processor sürümünü 0.12.0 yapıp yeniden derleyin.
Eski açık SELECT kaynakları ve metadata/codec factory'leri desteklenir.
Yeni depo kaydı, arka plan yazıcısı veya GET sırasında SQL eklenmez.
Mapping değişikliğinde sıralama, tekrarlar, null ve boş listeler dahil tam cevabı
karşılaştırın. Cevap için liste, yalnızca üyelik kontrolü için küme kullanın.

Kaynak record'ları scalar alanlı, public, generic olmayan ayrı sınıflardır.
İki kolonlu ilişki yardımcısı String kimlik kullanır.
Genel satır yardımcıları farklı anahtar tipleriyle de çalışır.
İş filtreleri ve DTO kuralları tahmin edilmez.
Oracle'da tırnakla tanımlanan karma harfli nesneler için açık SQL gerekir.
