# v0.10.0

İngilizce sürüm: [../../../docs/releases/v0.10.0.md](../../../docs/releases/v0.10.0.md)

Sürüm etiketi: `v0.10.0`

CacheDB `0.10.0`; `0.9.0` sonrasında kalan dağıtım, migration scaffold, SQL
Server yazma yolu ve uygulama geçiş kanıtı açıklarını kapatan kararlı ve
eklemeli framework sürümüdür.

## Temel Değişiklikler

- Migration scaffold artık gerçek bir `@CacheProjectionRecord`, entity
  tarafındaki `@CacheProjectionDefinition` kayıt bağlantısı ve sınırlandırılmış
  `PartitionedRelationBatchLoader` üretir. Üretilen dosyalar gerçek CacheDB
  annotation processor'larıyla integration test içinde derlenir.
- Planlayıcıda seçilen doğrudan projection kolonları otomatik eşlenir. Primary
  key, relation key ve sort key her zaman eklenir. Hesaplanan business alanları,
  metadata üzerinden güvenli biçimde çıkarılamayacağı için açık uygulama kararı
  olarak kalır.
- Generated entity ve projection codec'leri UUID, `Instant`, `LocalDate`,
  `LocalTime`, `LocalDateTime` ve mevcut scalar tipleri destekler.
- SQL Server tarafında aynı şekle sahip yazmalar toplu update, sonuçlanmayan
  satırlar için tek kilitli version sorgusu ve gerçekten bulunmayan satırlar
  için toplu insert olarak çalışır. Eski version no-op, version çakışması hata
  olmaya devam eder.
- Canlı SQL Server kanıt hattı makine tarafından okunabilen throughput raporu
  üretir, alt performans eşiğini zorunlu tutar ve container yeniden başladıktan
  sonra testi tekrarlar.
- Yeni `cachedb:certify` Maven hedefi, uygulama kanıtlarını tek commit ve ortama
  bağlar. Rota envanteri, veri eşitliği, Redis belleği, failover, canary, geri
  dönüş veya engel bilgisi eksikse `mvn verify` başarısız olur.
- Public artifact'ler `https://esasmer-dou.github.io/cache-database/maven2`
  adresinden kimlik doğrulaması olmadan indirilebilir. GitHub Packages, isteğe
  bağlı kimlik doğrulamalı ayna olarak kalır.
- [Production Olgunluğu](../production-olgunlugu.md), güncel olgunluk ve yayına
  çıkma kararı için tek kaynaktır.

## Consumer Kurulumu

```xml
<repositories>
    <repository>
        <id>cachedb-public</id>
        <url>https://esasmer-dou.github.io/cache-database/maven2</url>
    </repository>
</repositories>
<pluginRepositories>
    <pluginRepository>
        <id>cachedb-public</id>
        <url>https://esasmer-dou.github.io/cache-database/maven2</url>
    </pluginRepository>
</pluginRepositories>

<properties>
    <cachedb.version>0.10.0</cachedb.version>
</properties>
```

GitHub token'ı veya CacheDB kaynak kodunu yerelde derlemek gerekmez.

## Production Sertifikası

[Production Sertifikası](../production-sertifikasi.md) belgesindeki
`cachedb-maven-plugin:certify` çalıştırmasını ekledikten sonra şu komutu kullan:

```bash
mvn verify -Pproduction-certification
```

Framework release kanıtı, uygulamanın geçiş sertifikası değildir. Her uygulama;
rota, veri eşitliği, bellek, failover, canary ve geri dönüş kanıtını kendi
staging topolojisinde üretmelidir.

## Uyumluluk

- Mevcut `0.9.0` repository tanımları kaynak kod düzeyinde uyumludur.
- Redis-first HOT route'lar, açık ve sınırlı SQL kaynak route'ları, asenkron SQL
  kalıcılığı ve reflection kullanmayan generated implementasyonlar değişmedi.
- PostgreSQL ile SQL Server aynı uygulama modelini kullanır; provider'a özgü SQL
  ve operasyon ayarları ayrı kalır.
