# CacheDB 0.18.1

[English](../../docs/releases/v0.18.1.md)

Bu yama, 0.18.0 ile gelen davranışları sağlamlaştırır. Kaynak kodun hazırlanması
yayın anlamına gelmez: mevcut 0.18.0 tag'i ve paketleri değiştirilmez.
0.18.1 gerçekten yayımlanmadan bu sürümü public Maven deposundan çekmeyin.

## Değişiklikler ve Geçiş

| Risk | Değişiklik | Uygulamada yapılacak iş |
| --- | --- | --- |
| R-1 | Bileşik indeks imzası; VERIFIED/PENDING_REBUILD/NONE durumları; sınırlı temizleme ve doğru tek kolon fallback yolu | Binding'leri üretin, bütün yazıcıları güncelleyin, sonra rebuildIndexes çalıştırın. Farklı binding sürümleri yazarken yeniden kurma yapmayın. |
| R-2 | JDBC gruplama sayaçları; flusher başına en fazla 1024 entity adı için ilk kullanım kaydı | Yalnızca sıra bağımsız şemalarda açın; reorderedBatches, reorderedOperations ve reorderSkippedMixedOptIn sayaçlarını izleyin. |
| R-3 | Slota göre sınırlı causal okuma ve görev kapsamını açıkça taşıma | Tenant yetkisini ve causal kapsamını ayrı taşıyın. Atomik yazmalar yine ortak hash tag gerektirir. |
| R-4 | İlk kullanımda açılan runtime'a özel havuz; en fazla 2 thread, 256 kuyruk girdisi ve 258 rezervasyon | Runtime'ı kapatın; I/O zaman aşımlarını sonlu tutun. Java, interrupt isteğini yok sayan görevi zorla durduramaz. |
| R-6 | Kaynak ve test dizinlerinin hizalanması | Java paket adları ve üretilen sınıfların binary adları değişmez. |
| R-7 | Mevcut provider workflow'unda canlı altyapıyla tam reaktör ve skip denetimi | Zorunlu kanıt eksikse kontrol geçmez; yalnızca unit testlerin geçmesi yeterli değildir. |

**R-5, 0.19.0'a ertelendi.** Tenant aggregate ve facet sorguları mevcut sınırlı
ve doğru pipeline yolunu kullanır. Bu yamada bu alanlar için Lua hızlanması iddia edilmez.

## Bağımsız Yazma Gruplamasını Açma

```java
@CacheEntity(table = "supplier_offers", redisNamespace = "supplier-offers",
        independentWriteReordering = true)
public class SupplierOffer { /* kalıcı alanlar */ }
```

Flush batch'indeki bütün entity'ler izin vermelidir. Aynı `(tablo,id)` işlemlerinin
sırası korunur. Üst/alt tablo eklemelerinde, kardeş satır okuyan trigger'larda,
satırlar arasında unique değer değişiminde ve diğer sıra bağımlılıklarında ayarı
kapalı bırakın. Sayaçlar planlamayı gösterir; SQL commit kanıtı değildir.

[Causal kapsam, Cluster ve indeks yaşam döngüsü](../yakin-onbellek-facet-bilesik-indeksler.md)
ile [yazma kontrollerini](../aktif-veri-performans-kontrolleri.md) inceleyin.

## Doğrulama

Son kaynak kod, 2026-10-27 tarihinde EmaTech Kubernetes üzerinde doğrulandı:

| Kontrol | Sonuç |
| --- | --- |
| 23 modüllü tam reaktör | 743 test kaydı; 741 çalıştı, özel topoloji gerektiren 2 test atlandı; failure/error yok |
| Zorunlu release testleri | Tamamı çalıştı; bileşik indeks geçişi, slota göre causal okuma ve yenileme yaşam döngüsü dâhil |
| PostgreSQL / SQL Server / Oracle tüketimi | Her birinde 33 test; failure/error/skip yok; provider başına 13 staged CacheDB JAR hash'i doğrulandı |
| Paketlenmiş Jackson'sız yol | 315/315 ilk ve tekrar ölçüm 50 ms altında; en yüksek süre 43,334754 ms |
| API, paket ve benchmark eşikleri | Mevcut API üyeleri korundu; 19 binary/source/Javadoc grubu ve 21 staged POM doğrulandı; eşikler geçti |
| Doküman ve kaynak sözleşmeleri | EN/TR kalite, bağlantı, derlenen sample örnekleri, dizin düzeni, provider eşliği ve API koleksiyonları geçti |

Çalışma alanı Java 21, 2 CPU ve 4 GiB ile sınırlandı. Geçici fixture'larda Redis
8.2.1, PostgreSQL 17.6, SQL Server 2022 ve Oracle Free 23.9 kullanıldı. Atlanan
iki test, `MssqlListenerFailoverSqlServerTest` ve
`OracleServiceNameFailoverIntegrationTest` oldu; özel failover topolojileri kurulu
değildi. Zorunlu Redis/provider testleri atlanmadı. Güncellenen workflow ve skip
denetimi yerelde hazırlandı; push yapılmadan yeni remote CI koşusu veya yayın
gerçekleşmiş sayılmaz. 50 ms kapısı bir HTTP/WAN gecikmesi garantisi değildir.

Kabul koşusu, EmaTech Kubernetes üzerinde ayrı namespace'te; tekil Redis,
altı düğümlü Redis Cluster ve geçici PostgreSQL, SQL Server, Oracle veritabanlarıyla
çalıştırılmalıdır. Modül sonuçları Maven XML raporlarından alınır.
`tools/ci/check-full-environment-tests.ps1`, eksik veya bütünüyle atlanmış zorunlu
test gruplarını ve atlanan canlı yenileme testlerini reddeder. Paket ve API
kontrolleri aynı kaynak kod üzerinde uygulanır. Bu kanıt, müşteriye özel HA,
WAN gecikmesi veya uygulama geçiş onayı değildir.

Bu yama Lua kaynağını değiştirmediği için Redis Function kütüphanesinin ABI sürümü
0.18.0 olarak kalır. Maven paketinin sürümü 0.18.1'dir. Function sürümünü zorla
değiştirmeyin ve mevcut Redis sürüm sayaçlarını sıfırlamayın.
