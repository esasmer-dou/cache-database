# v0.11.0

İngilizce sürüm: [../../../docs/releases/v0.11.0.md](../../../docs/releases/v0.11.0.md)

Sürüm etiketi: `v0.11.0`

CacheDB `0.11.0`, yeni veritabanı sağlayıcısı ekleyen ve mevcut kullanımlarla
uyumlu bir özellik sürümüdür. Oracle Database; Redis öncelikli aktif rotalar,
açık SQL kaynak rotaları, projection, ön yükleme ve write-behind modelini
değiştirmeden PostgreSQL ile SQL Server'ın yanında eşit seviyede desteklenir.

## Tanımla Katalog Yenileme

[SnapshotPlan](../snapshot-projectionlar.md) ile kaynak tabloları, iş kuralını ve yenileme
ayarını tanımlayın. Uygulamaya ayrı loader ve warmer yazmanız gerekmez. Geçici dosya,
partileme, yenilenen kilit ve tamamlanan katalogun tek adımda yayımlanması framework'e aittir.
PostgreSQL, SQL Server ve Oracle kaynakları transaction boyunca tutarlı okunur.
Hatalı hazırlık önceki başarılı katalogu değiştirmez. SQL Server için DBA tarafından
ALLOW_SNAPSHOT_ISOLATION açılmalıdır; framework veritabanı ayarını değiştirmez.

## Temel Değişiklikler

- Oracle JDBC Thin ve `ojdbc17` kullanan `cachedb-storage-oracle` ile
  `cachedb-spring-boot-starter-oracle` modülleri eklendi.
- Oracle için sürüm kontrollü ve JDBC batch kullanan `MERGE`, aynı kaydı ekleme
  yarışında güvenli toparlanma, kontrollü silme, sorgu zaman aşımı, transaction
  isolation, yeniden deneme sayısı ve boş metin politikası eklendi.
- Oracle okumaları; 900 ifadeli güvenli `IN` parçaları, satır sınırı,
  sağlayıcıya özel değer bağlama ve bilinmeyen veritabanında başlangıcı durduran
  ürün kontrolüyle sınırlandırıldı.
- Oracle outbox okuma ve checkpoint mekanizması çok pod'lu kullanıma uygun,
  tekrarlanabilir claim davranışıyla eklendi. Oracle DDL mevcut transaction'ı
  commit ettiği için çalışma zamanında DDL üretimi varsayılan olarak kapalıdır.
- Oracle şema keşfi, foreign key üzerinden rota önerisi, dry-run ve staging ön
  yükleme, yan yana veri eşitliği karşılaştırması ve Redis bellek tahmini eklendi.
- Sağlayıcıya özel `JdbcSchemaDialect` eklendi. Tablo oluşturma, doğrulama ve
  migration artık PostgreSQL, SQL Server, Oracle ve H2 testlerinde doğru veri
  tipini, metadata harf düzenini ve DDL sözdizimini kullanır.
- Şema hazırlama veya doğrulama hata verirse uygulama başlangıcı durur. Hatalı
  şemayla çalışmaya devam eden sessiz başlangıç davranışı kaldırıldı.
- Docker Compose, Oracle DDL, seed ve ön yükleme rotaları, 59 Postman isteği,
  Türkçe/İngilizce rehberler ve canlı Oracle/Redis testleri içeren Java 21 REST
  örneği eklendi.
- Oracle kanıt hattı; yazma ve silme, eski sürüm, eş zamanlı upsert, büyük `IN`
  listeleri, outbox checkpoint'i, çok pod koordinasyonu, gecikmeli ağ, container
  yeniden başlatma, migration veri eşitliği ve asgari throughput kontrolünü
  kapsar.
- İki Oracle 19c instance'ı kullanan self-hosted fiziksel Data Guard hattı
  eklendi. Hat; redo uygulamayı, broker doğrulamasını, planlı switchover'ı,
  primary kaybını, çok adresli tek servis adlı JDBC tanımı üzerinden Hikari
  toparlanmasını, iki rol geçişinden sonra provider testlerinin tamamını ve eski
  primary'nin yeniden standby yapılarak son boşluksuz/sıfır gecikmeli hazırlık
  kontrolünü çalıştırır.
- Gecikmeli ağ testi artık hedef host, port ve servis adını verilen Oracle Easy
  Connect adresinden alır. Planner ön yükleme SQL'inden JDBC statement'ı için
  geçersiz olan sonlandırıcı kaldırıldı.

## Uygulama Kurulumu

```xml
<properties>
    <cachedb.version>0.11.0</cachedb.version>
</properties>

<dependency>
    <groupId>com.reactor.cachedb</groupId>
    <artifactId>cachedb-spring-boot-starter-oracle</artifactId>
</dependency>
```

```yaml
cachedb:
  sql:
    provider: ORACLE
    oracle:
      query-timeout-seconds: 10
      transaction-isolation: READ_COMMITTED
      duplicate-race-retries: 2
      empty-string-policy: REJECT
```

Kimliği uygulamada veya Redis tarafında üret ve açık bir sayısal sürüm kolonu
kullan. Sözleşmenin tamamı için [Oracle Sağlayıcı Rehberi](../oracle-provider.md)
belgesini oku.

## Desteklenen Oracle Kapsamı

- Oracle Database 19c ve üzeri
- `ojdbc17` ile Oracle JDBC Thin
- üretilen entity repository'leri, projection, ön yükleme/backfill, migration
  keşfi ve karşılaştırması, write-behind ve outbox apply
- sağlayıcı rehberinde belirtilen temel JDBC veri tipleri

Genel amaçlı PL/SQL procedure eşleme, Oracle UDT/ARRAY/STRUCT, XMLTYPE, SDO ve
LOB streaming bu sürümün kapsamına girmez. Bu işlemleri uygulamaya özel, açık
SQL adapter'larında tut.

## Uyumluluk

- PostgreSQL ve SQL Server uygulama API'leri kaynak kod düzeyinde uyumludur.
- `JdbcStorageProvider.schemaDialect()` varsayılan implementasyon içerir; mevcut
  üçüncü taraf sağlayıcılar derlenmeye devam eder.
- Otomatik şema doğrulama veya oluşturmayı açıp hataların yok sayılmasına
  güvenen uygulamalar artık başlangıçta durur. Bu bilinçli bir doğruluk
  kontrolüdür; şemayı düzelt veya otomatik hazırlamayı açıkça kapat.
- Oracle boş metinleri varsayılan olarak reddedilir. Entity sözleşmesi null
  değere izin veriyorsa `NORMALIZE_TO_NULL` seçilebilir.
