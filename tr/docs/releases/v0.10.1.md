# v0.10.1

İngilizce sürüm: [../../../docs/releases/v0.10.1.md](../../../docs/releases/v0.10.1.md)

Sürüm etiketi: `v0.10.1`

CacheDB `0.10.1`, `0.10.0` üzerine gelen kararlı bir dağıtım tutarlılığı
düzeltmesidir. Çalışma zamanı veya üretilen public API değişmez.

## Düzeltilen Alanlar

- Framework reposunun içindeki PostgreSQL ve SQL Server örnekleri artık
  bağımsız örnek projelerle aynı anonim Maven deposu sözleşmesini kullanır.
- Örnek workflow'ları, varsayılan derleme için gereksiz GitHub Packages izni
  veya kimlik bilgisi istemez.
- Her örnek CI akışı, uygulama kanıt manifesti ya da route kapsam raporu yoksa
  `cachedb:certify` kontrolünün derlemeyi durdurduğunu doğrular.
- Public Maven yayını, resmi GitHub Pages action'larının güncel Node 24
  neslini kullanır; önceki çalışma zamanı uyarısı kaldırılmıştır.
- Güncel README, başlangıç, provider, release, OpenRewrite ve paket
  referanslarının tamamı değişmez `0.10.1` artifact'lerini gösterir.

## Dağıtım

Resmi Maven deposu için token gerekmez:

```xml
<repository>
    <id>cachedb-public</id>
    <url>https://esasmer-dou.github.io/cache-database/maven2</url>
</repository>
```

BOM, provider starter ve Maven plugin için `0.10.1` kullan. GitHub Packages,
isteğe bağlı ve kimlik doğrulamalı bir ayna olarak kalır.

## Uyumluluk

- `0.10.0` etiketi ve artifact'leri değişmeden kalır.
- Çalışma zamanı veya generated public API imzası kaldırılmadı ve değiştirilmedi.
- PostgreSQL ile SQL Server aynı provider sözleşmesini ve kanıt hatlarını korur.
- Her uygulama, kendi route'ları ve staging topolojisi için production
  sertifikasını ayrıca üretmelidir.

## Doğrulama

- Tam reactor, public API, doküman, örnek proje eşitliği ve release artifact
  kontrolleri geçmelidir.
- Tag yayımlanmadan önce Framework Readiness ve Production Evidence, release
  commit'inin tamamı için başarılı olmalıdır.
- İki bağımsız örnek proje de boş bir yerel Maven deposuyla, anonim CacheDB
  deposundan derlenmelidir.
- GitHub Release içinde release ZIP'i, SHA-256 dosyası ve public binary JAR'lar
  bulunmalıdır.
