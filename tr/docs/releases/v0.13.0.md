# CacheDB 0.13.0

Bu framework sürümü, SNAPSHOT veya ön sürüm eki olmadan `0.13.0` numarasını kullanır.
BOM, sağlayıcı starter'ları, annotation processor ve örnek projeler aynı sürümdedir.
Redis öncelikli okumalar ve açık SQL yolları korunur; yeni API'ler otomatik SQL
fallback eklemez.

## Yeni API'ler

- Kaynak record'larında OffsetDateTime, LocalTime, BigInteger, Float, Short, Byte ve enum için üretilmiş dönüşüm desteği vardır.
- Long/UUID ilişkilerinde iki yön de aynı SQL kaynağını kullanır.
- Parametreli snapshot filtrelerine karşılaştırma, aralık, null ve sabit değer listesi eklenir.
- Açık bölüm indeksleri SQL çalıştırmadan sınırlı CursorPage okuması sağlar.
- Açık kök kapsamı, seçilen kayıtların atomik yenilenmesini sağlar; değişmeyen JSON nesiller arasında paylaşılabilir.
- Outbox bölümleri bağımsız checkpoint kullanır ve entity başına olay sırasını korur.
- CacheWriteBatch tek zarf kabul eder; desteklenen her sağlayıcı bunu tek SQL transaction içinde yazar.
- Ortak SQL sequence'in gerçek ayrılmış kimlikleri diğer uygulamalarla güvenle paylaşılır.
- Redis adaptörleri tek sunucu ve Cluster için açık, aynı slot'ta atomik kapsamı destekler.

## Yükseltme Kontrolleri

BOM, annotation processor ve sağlayıcı starter'ını
`0.13.0` ile eşitleyin; üretilmiş binding'leri yeniden derleyin. Sürüm numarası tek
başına uygulamanın veri kapsamını, bellek bütçesini veya failover topolojisini doğrulamaz.

CacheDB BOM, gereken Jedis sürümünü (5.2.0) belirtir. Spring Boot parent kullanırken
kurulum örnekleri ve örnek POM'larda olduğu gibi `<jedis.version>5.2.0</jedis.version>`
ayarını da ekleyin. Aksi durumda parent POM'un bağımlılık yönetimi, adaptörlerin
kullandığı pipeline API'sini içermeyen eski sürücüyü seçebilir.

Primitive boolean alanına SQL NULL gelirse artık hata verilir. Nullable kolon için
Boolean kullanın. hotEntityLimit=0 entity kabulünü kapatır; eski sınırsız ayarı -1 yapın.
Belirtilmemiş limitin varsayılanı 1.000 olarak korunur.
Eski public metot ve constructor'lar durur; üretilmiş binding'leri yeniden derleyin.
Snapshot ve kuyruk record'larında ek bileşenler vardır. Uygulamanızın record pattern,
serileştirme ve eşitlik varsayımlarını kontrol edin.
Yeni katalog saklama biçimi indeks/referans metadata'sı içerir. Mevcut yayında biçim
değiştirmeden önce ayrı namespace hazırlayın ve veri eşleşmesini doğrulayın.

Batch kabulü Redis/SQL arasında dağıtık commit değildir. Sınırlı tenant sözleşmesi
kotayı atlamak yerine atomik batch'i reddeder. Sorgu indeksi geçersizleştirildiğinde
ayarlanmış rebuild/strict-route davranışı kullanılır. Tek atomik Cluster kapsamı tek
slot'ta kalır; kendi kendine farklı node'lara bölünmez.

## Paketleri Kullanma

derlemesi gerekmez. GitHub Packages ek bir dağıtım kanalıdır ve Maven kimlik bilgisi ister.
[GitHub sürümünde](https://github.com/esasmer-dou/cache-database/releases/tag/v0.13.0)
binary, kaynak ve Javadoc JAR'ları, parent/BOM POM'ları, paket ve SHA-256 doğrulama dosyaları bulunur.

## Doğrulamanın Sınırı

Bu sürüm için yeni bir fiziksel Oracle Data Guard failover doğrulaması yapıldığı iddia edilmez.
Gerekli lisanslı Enterprise test image'ı ve self-hosted runner bu sürümde kullanılamadı.
Çalıştırılamayan test, başarılı test değildir. RAC, Data Guard, SQL Server Always On ve
yönetilen Redis kurtarma davranışı, kullanılacak kurulum üzerinde ayrıca doğrulanmalıdır.
Paketin yayımlanması, tam production GA onayı veya uygulamanın geçiş sertifikası anlamına gelmez.

[kaynak başvurusunu](../snapshot-kaynak-basvurusu.md) ve
