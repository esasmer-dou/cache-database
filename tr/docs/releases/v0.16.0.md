# CacheDB 0.16.0

[English](../../../docs/releases/v0.16.0.md)

## Değişiklikler

- Seçili kolonlara ait indeks metadata'sı, toplu kayıtta tek kolon çıkarımı,
  birleştirilmiş LRU/tenant erişimleri ve haritasız üretilen filtre/sıralama erişimi.
- Kimlik, sayfa ve sorgu eksiklerinde sınırlı single-flight; ayarlanabilir erişim
  birleştirme aralığı. Çağıranlar aynı değiştirilebilir nesneyi paylaşmaz.
- Üretilen tipli `Binding.Columns` alanları ve snapshot filtre/kapsam metotları.
- Derleme sırasında doğrulanan `@CachePatch`; üç sağlayıcıda yalnızca değişen
  kolonları taşıyan kuyruk/SQL UPDATE ve önceki sürüm/silme koruması.
- SQL'e aktarım sonrası otomatik dirty-root bildirimi ve isteğe bağlı toplu yenileme.
- Yerel kalıcılık bekleyicilerine doğrudan bildirim; süreçler arasında artan bekleme.
- Programatik ve Spring `@CacheTransactional` işlem birimleri; gerçek kabul sonucu
  yalnızca commit sonrasında üretilir.
- Kuyruk, kurtarma ve iş metotlarında sınırlı izleme bağlamı; standart Micrometer
  binder ve Redis/SQL süre ölçümleri.
- İsteğe bağlı, kayıt/bayt/süre sınırı olan L1; pod'lar arası geçersiz kılma,
  bağlantı kesilmesinde Redis'e dönüş ve geç kalan doldurmaya karşı koruma.
- Üç Java 21 örnekte tipli kolon, mutlak stok PATCH ve otomatik snapshot bağlantısı.
  Kütüphane Java 17 bytecode üretmeyi sürdürür.

## Doğrulama

- Tam reactor koşusu: 668 testte hata yok. Ortam gerektiren iki listener /
  service-name failover testi çalıştırılmadı.
- PostgreSQL, SQL Server ve Oracle örneklerinde sağlayıcı başına 26 testin tamamı geçti.
- Paketlenmiş Jackson'sız codec için ilk kullanım ve tekrarları kapsayan 1260
  ölçümün tamamı 50 ms altında; en yüksek değer 33,66 ms. Bu bir codec ölçümüdür,
  REST veya veritabanı gecikme garantisi değildir.
- Eski Jackson sözleşmeleri ayrıca doğrulandı. İlk kullanımda ölçülen en yüksek
  397 ms, Jackson'sız yolun süre sınırından ayrı raporlandı.
- Üç örnek de framework kaynakları olmadan hazırlanan Maven paketleriyle derlendi.
  Public API uyumluluğu, kütüphanelerin Java 17 ve örneklerin Java 21 bytecode
  sürümleri kontrol edildi.

Bu sonuçlar yalıtılmış Kubernetes test kaynaklarına aittir; uygulamaya özel HA
topolojisi veya kapasite sertifikası değildir.

## Geçiş ve Sınırlar

Özellikleri açmadan önce [okuma ve yazma kontrollerini](../aktif-veri-performans-kontrolleri.md)
inceleyin. Bütün artifact sürümlerini hizalayıp binding'leri yeniden üretin. PATCH
üretimini açmadan önce eski işçileri durdurup kuyruğu boşaltın. Fence metadata'sını
ve Redis sürüm sayaçlarını koruyun. İndeks kapsamı açıkça daraltılmadıkça değişmez.
İş tablolarına yeni kolon eklemek gerekmez.

L1 anlık tutarlılık sunmaz; pub/sub kalıcı bir günlük değildir. Otomatik dirty-root
bildirimi periyodik uzlaştırmanın veya harici yazmalar için CDC'nin yerine geçmez.
İşlem birimi 100 kimlik, 4 MiB ve 2000 kuyruk alanıyla sınırlıdır; Cluster aynı
hash-tag kapsamını ister. Kabul sonrasında bekleme süresinin dolması rollback
değildir. Ertelenmiş işlem içinde receipt döndüren metot yerine açık `tx` komutları
kullanılmalıdır. Bu sürüm, uygulamaya özel HA, RAC veya Data Guard sertifikası değildir.
