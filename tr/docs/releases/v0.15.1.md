# CacheDB 0.15.1

English: [0.15.1 release notes](../../../docs/releases/v0.15.1.md)

## Değişiklikler

- Şema kurulumu, DDL dışa aktarımı, migration keşfi/planlaması ve SQL write-behind,
  JDBC'nin bildirdiği sınırlı kolon kapasitesini kullanır. Kapasite bilinmiyorsa
  veya sürücü bu bilgiyi desteklemiyorsa Oracle için 1000, SQL Server için 1024,
  PostgreSQL için 1600 esas alınır.
- Entity verisi, projection şeması, Redis indeks güncellemesi ve yönetim paneli
  dışa aktarımı en fazla 4096 alan kabul eder. Veri boyutu, sorgu ve bellek
  bütçeleri korunur.
- Geniş entity'ler için üretilen codec/metamodel kodu küçük metotlara bölünür.
  Böylece JVM'in metot boyutu sınırı aşılmaz. 1000 alan üzerinde sağlayıcı
  sınırlarının kontrol edilmesini isteyen not, 4096 üzerinde derleme hatası
  üretilir. Büyük record constructor'ları için JVM sınırı açıkça bildirilir.
- Fiziksel kolon sayısına ayrı ID, sürüm ve silinme kolonları da katılır.
  Migration planı mevcut eşlenmemiş kolonları da sayar. Tek satırın SQL parametre
  bütçesi aşılırsa batch boyutu bire düşürülerek sorun gizlenmez.
- Kolon başına metadata çağrısı yerine tablo başına sınırlı bir sonuç kümesi
  okunur. Tablo/şema adlarındaki joker karakterler doğru biçimde kaçırılır.
- Java 21 kullanan üç sample'ın BOM, processor, starter ve doctor plugin
  sürümleri 0.15.1'e eşitlendi. Türkçe/İngilizce kolon güvenliği örnekleri eklendi.
  Kütüphanenin Java 17 bytecode seviyesi ve mevcut REST yolları korundu.

## Yükseltme

1. Tüm CacheDB bağımlılıklarını ve annotation processor'ı 0.15.1'e eşitle.
   Binding'leri yeniden üret; processor/core sürümlerini karıştırma.
2. 1024 alanı aşan verileri yazmadan önce tüm okuyucu ve worker'ları yükselt.
   Eski 0.15.0 okuyucuları önceki sınırı uygulamaya devam eder. Daha küçük
   verilerin biçimi, null ve tekrarlanan alan davranışları korunur.
3. Yazma açılmadan önce bağlı şemayı doğrula. Daha önce genel sınıra sığdığı
   hâlde veritabanına sığmayan tanımlar artık bilerek reddedilir. Sürüm ve
   mantıksal silme kolonlarını da toplama kat.
4. Kalıcı sürüm koruma tablosu kurulmuş bir 0.15.0 uygulamasında bu yama için ek
   iş tablosu migration'ı gerekmez. Daha eski, korumasız worker'lar için
   [kalıcı sürüm tablosu migration'ı](../kalici-yazma-surumleri.md) ve koordineli
   devreden çıkarma gerekir. Sürüm sayaçlarını yükseltme sırasında koru.
5. Daha yüksek alan tavanını tüm geniş tabloyu liste ekranına yüklemek için
   kullanma. Ekrana özgü dar projection'ları tercih et.

## Doğrulama ve Sınırlar

Doğrulama, EmaTech Kubernetes'teki geçici test kaynaklarında yapılır: tam reactor,
canlı PostgreSQL/SQL Server/Oracle kolon sınırı yazıları, altı düğümlü Redis
Cluster, public API uyumluluğu, paketlenmiş üretilmiş codec süreleri ve üç
sample'ın sağlayıcı entegrasyon testleri. Doğrulanmış JAR'lar yayın kanallarına
yeniden derlenmeden aktarılır. Yayından sonra anonim Maven tüketimi, kaynak
projenin derlemesinden ayrı olarak kontrol edilir.

50 ms kapısı, üretilmiş codec/snapshot senaryolarını kapsar. Senaryonun ilk
kullanımı ölçülür; JVM başlatma ve derleme ölçülmez. Bu bir REST, SQL, WAN veya
canlı ortam kapasite garantisi değildir. Eski mapper API'lerinin işlevselliği
uyumluluk testlerinde korunur.

Canlı Oracle test kurulumu 1000 kolon bildirir. Metadata/DDL testlerinde 4096
yolu sınanır; 4096 alanlı sınıf gerçekten derlenip gidiş-dönüş doğrulanır.
Bunlar canlı Oracle extended kurulumu kanıtı değildir. CacheDB `MAX_COLUMNS`
ayarını kendiliğinden açmaz. Gerçek sürücü/veritabanı ayarları, satır genişliği,
silinmiş kolon yuvaları ve SQL parametre sınırları daha düşük kapasite getirebilir.

Oracle service-name rol geçişi ve SQL Server listener failover senaryoları ayrı,
koordineli test topolojisi gerektirir. Bu framework paketi; RAC/Data Guard,
Always On veya uygulamanın canlıya geçiş sertifikası değildir.

Örnekler ve sağlayıcıya özgü sınırlar için [kolon ve alan sınırlarını](../sema-kolon-sinirlari.md)
oku. Anonim Maven deposu `https://esasmer-dou.github.io/cache-database/maven2`
olarak kalır. GitHub Packages ek, kimlik doğrulamalı dağıtım kanalıdır; sample'ları
kullanmak için zorunlu değildir.
